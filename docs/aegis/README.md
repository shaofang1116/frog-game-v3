# Aegis Engineering Workspace

This directory stores durable engineering artifacts for `frog-game-v2`.

- `baseline/`: evidence snapshots of accepted product and runtime boundaries.
- `specs/`: reviewed feature and architecture designs.
- `plans/`: executable implementation plans created from approved specs.
- `INDEX.md`: artifact index.
- `BASELINE-GOVERNANCE.md`: rules for distinguishing design defects from implementation drift.

These documents supplement `WORK_PLAN.md`. They do not replace the repository's
accepted baselines, tests, or human acceptance gates.
